# 🌿 Bio-Tech & Emerald Portfolio Theme (HTML5 & Blogger XML)

Modern, hızlı, zümrüt yeşili & biyo-teknoloji karanlık temalı kişisel web sitesi ve portfolyo şablonu. Hem doğrudan tarayıcıda (`index.html`) çalışır hem de **Google Blogger / Blogspot** (`blogger-theme.xml`) altyapısına %100 uyumludur.

---

## ✨ Özellikler

- **🌲 Zümrüt & Doğa-Teknoloji Teması:** Fütüristik ızgara dokusu (micro-grid) ve GPU hızlandırmalı yumuşak neon parıltılar.
- **📱 %100 Mobil ve Masaüstü Uyumlu:** Tüm cihazlarda akıcı çalışan modern responsive tasarım.
- **🎥 YouTube Kanal Vitrini:** Kendi kanalınız ve editörlük/içerik ürettiğiniz kanallar için zengin banner ve avatar önizleme kartları.
- **📸 Sağdan Sola Kayan Sonsuz Galeri (Infinite Marquee):** Fotoğraflarınızı sağdan sola akıcı şekilde sergileyen, fareyle durdurulabilen ve tıklandığında tam ekran açılan Lightbox modal.
- **🤖 Discord Bot Güvenlik & Gizlilik Sekmesi:** Discord Developer Portal politikalarıyla uyumlu, hazır Gizlilik Politikası ve Kullanım Koşulları sekmeleri.
- **⚡ Yüksek Performans & 0 ms Tepki:** Ağır filtreler yerine donanım hızlandırmalı CSS geçişleri, 0ms dokunma tepkisi.
- **📦 Sıfır Bağımlılık:** React, Vue veya ağır JS framework'lerine ihtiyaç duymaz; saf HTML, modern CSS ve vanilla JavaScript.

## 🚀 Kurulum & Kullanım

### 1. Yerel Olarak Çalıştırma
1. Bu depoyu indirin (`git clone https://github.com/ygiido/ygiido-portfolyo-web-site.git`).
2. `index.html` dosyasına çift tıklayarak tarayıcınızda açın.

### 2. Blogger'a (Blogspot) Yükleme
1. [Blogger](https://www.blogger.com) yönetim paneline girin.
2. Sol menüden **Tema (Theme)** sekmesine tıklayın.
3. Özelleştir butonunun yanındaki aşağı ok (▼) simgesine tıklayıp **Geri Yükle (Restore)** seçeneğini seçin.
4. **Yükle (Upload)** butonuna basarak bu depodaki `blogger-theme.xml` dosyasını seçin.
5. Siteniz saniyeler içinde yeni modern temasıyla yayına hazır olacaktır!
